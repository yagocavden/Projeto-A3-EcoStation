# ♻️ Smart Reciclagem

## Sobre o Projeto

O Smart Reciclagem é um projeto que utiliza inteligência artificial e sensores inteligentes para otimizar a coleta seletiva. O sistema identifica diferentes tipos de resíduos, monitora a capacidade das lixeiras e auxilia no planejamento das rotas de coleta, contribuindo para uma gestão de resíduos mais eficiente e sustentável.

## Integrantes

- Diego Oliveira Andrade
- Yago Ribeiro Cavden

## Objetivos

- Identificar e classificar diferentes tipos de resíduos.
- Monitorar o nível de preenchimento das lixeiras.
- Otimizar o planejamento das coletas.
- Promover a sustentabilidade e a destinação adequada dos resíduos.

## Tecnologias

- Inteligência Artificial
- Sensores inteligentes
- Sistema de monitoramento
- Desenvolvimento de software
